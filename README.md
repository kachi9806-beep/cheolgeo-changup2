# 365철거 랜딩페이지

상가 · 매장철거 전문 365철거 원페이지 랜딩. 프레임워크 없는 정적 사이트라 빌드 과정이 없음.

## 로컬 확인

빌드 도구 불필요. 아래 중 하나로 실행.

```bash
# 방법 1. 정적 서버 (권장)
npx serve .

# 방법 2. 파이썬 내장 서버
python3 -m http.server 5500
```

브라우저에서 `http://localhost:3000` (serve) 또는 `http://localhost:5500` 접속.

## Vercel 배포

무설정 정적 배포.

```bash
vercel        # 미리보기 배포
vercel --prod # 프로덕션 배포
```

Vercel 대시보드에서 폴더를 연결할 경우 Framework Preset은 `Other`, Output Directory는 비워둠 (루트의 index.html 자동 서빙).

## 구성

```
index.html    8개 섹션 마크업 + 플로팅 전화 버튼
styles.css    다크 테마, 480px 스탠드형 컬럼, 480px 미만 vw 비례 축소
script.js     스크롤 등장 효과 + 사례 사진 슬라이드
assets/       3D 픽토그램 12종, 현장 사진 8장
```

## CTA 동작

모든 CTA가 전화 직통(`tel:01057698933`). 상담 모달과 입력 폼은 없음. 히어로를 지나면 하단에 전화 버튼이 떠오르고, 마지막 섹션에 닿으면 사라짐.

## 현장 사례 슬라이드

외부 캐러셀 라이브러리 없이 CSS `scroll-snap` 으로 구현.

- 모바일은 손가락으로 밀어서 넘김. PC는 좌우 화살표
- 하단 점 8개로 현재 위치 표시. 점을 눌러 이동 가능
- 4초마다 자동으로 넘어감
- 사용자가 한 번이라도 조작하면 자동 넘김이 멈추고 다시 켜지지 않음
- 화면 밖이거나 탭이 가려지면 돌지 않음. 동작 축소 설정을 켠 사용자에게는 자동 넘김을 시작하지 않음

## 교체 필요 항목

### 전화번호 변경 시

`index.html` 의 `tel:01057698933` 9곳과 화면에 보이는 번호 표기를 함께 수정. 하나라도 놓치면 다른 번호로 연결됨.

```bash
grep -c 'tel:01057698933' index.html   # 9가 나와야 함
```

### 현장 사진 교체 시

`assets/case-01.jpg` 부터 `case-08.jpg`. 긴 변 1200px, JPEG 품질 78 기준으로 넣을 것. 원본 그대로 올리면 한 장에 3MB가 붙어 모바일에서 느려짐.

**실제 시공한 현장 사진만 사용.** 시공하지 않은 현장을 완료 사례로 게시하면 표시광고법 위반.

### 철거지원금 주의 문구

아래 두 줄은 삭제하지 않음. 지원금 지급을 보장하는 광고가 됨.

```
지원금은 조건과 상황에 따라 달라질 수 있으며
확정 지급을 보장하는 내용은 아닙니다
```

## 반응형 기준

- 기준 컬럼 폭 480px. Figma 시안 기준폭 860px, 환산 계수 `480 / 860 = 0.5581`
- 480px 미만은 `@media (max-width: 479px)` 에서 vw 비례 축소. `vw = 기준px / 480 * 100`
- 320px에서 520px까지 8개 폭에서 의도치 않은 줄바꿈 0건, 가로 오버플로 0건 확인
